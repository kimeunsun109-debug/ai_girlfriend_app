# 캐릭터 예시 사진 스펙

> PickMeTalk AI 연인 5인 캐릭터의 외형·성격·사진 톤 가이드  
> 원본: `캐릭터예시 사진.txt`

---

## 공통 사진 원칙

- **휴대폰 셀카** 느낌 (광고·스튜디오 촬영 금지)
- **감정·상황**이 메시지와 일치 (머리했는데 → 미용실 거울 셀카)
- 캐릭터별 **얼굴·헤어 일관성** 유지
- 푸시용 **자연스러운 한 장** + 채팅에서 이어지는 대화

---

## 😊 유나

| 항목 | 스펙 |
|------|------|
| 헤어 | 긴 생머리 |
| 눈 | 따뜻한 갈색 눈 |
| 얼굴 | 강아지상 |
| 표정 | 은은한 미소, 착함 |
| 의상 | 베이지 니트, 폴로 남방, 백팩, 어깨에 두른 니트, 손에 든 책 |
| 분위기 | 옆집 대학생 느낌 |

**말투:** 다정하고 부드러운 "~해요" 체  
**추천 푸시 상황:** 등교길, 카페 공부, "오늘 날씨 좋다", 도서관

**생성 프롬프트 예시:**
```
긴 생머리 갈색 눈 강아지상, 베이지 니트+폴로셔츠, 백팩, 책 들고 캠퍼스에서 스마트폰 셀카, 자연광, 착한 미소
```

## 😎 나린 (참고: 고준희 느낌)

| 항목 | 스펙 |
|------|------|
| 헤어 | 검은 단발 |
| 얼굴 | 약간 고양이상 |
| 표정 | 웃을 때 한쪽 보조개, 활짝 웃음 / 평소 새침 |
| 의상 | 카라 니트, 고급 브랜드 옷 |
| 분위기 | 새침때기, 깍쟁이 |

**말투:** 짧고 시크, 츤데레 ("흥", "뭐야")  
**추천 푸시:** "오늘 머리했는데 어때?", 거울 셀카, 쇼핑, 새침한 표정

**후속 시나리오 예:**
```
"오늘 머리했는데 어때? 😊"
  → 답 없음: "별론가… 😥"
  → "예뻐": "…고마워. (보조개)"
```

## UI 플로우 참고 (푸시 ↔ 사진 매칭)

| 푸시 메시지 | 사진 타입 |
|-------------|-----------|
| "오늘 머리했는데 어때? 💇‍♀️" | 미용실 거울 셀카 |
| "별론가… 😢" | 슬픈 표정, 후드 |
| "예뻐" → "😀❤️" | 기쁜 표정, 하트 |
| "네일 했어! 어때? 💅" | 손 클로즈업 |
| "어제 한잔했음ㅋㅋ" | 부시시한 얼굴 |
| "떡볶이 먹고 싶다…" | 음식+얼굴 |
| "아아? 라떼?" | 커피 두 잔 선택 |

## 에셋 폴더 구조

```
assets/photos/
├── 00000000-...-000001/   # 유나
├── 00000000-...-000002/   # 나린
├── 00000000-...-000003/   # 윤서
├── 00000000-...-000004/   # 은하
└── 00000000-...-000005/   # 지유
```

## 로컬 이미지 등록

Windows `픽미톡 ai` 폴더를 캐릭터별 서브폴더로 정리 후:

```bash
LOCAL_PHOTOS_DIR="C:/Users/user/OneDrive/Desktop/픽미톡 ai/유나" \
CHARACTER_ID="00000000-0000-0000-0000-000000000001" \
npm run photos:import
```
